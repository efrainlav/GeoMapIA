---

## 🚀 ¿Qué aprenderás en este curso (sin necesidad de saber programar antes)?

Aprenderás a comunicarte con modelos de Inteligencia Artificial mediante **Ingeniería de Prompts Geoespaciales (Framework C-T-D-E)** para diseñar, programar, depurar y publicar en internet aplicaciones cartográficas reales combinando **4 sectores estratégicos**:

1. 🌳 **Percepción Remota y Monitoreo Ambiental:** Comparadores satelitales multitemporales (*Split-Map*), focos de calor e índices espectrales (NDVI/NDWI).
2. 🏘️ **Catastro Multipropósito y Ordenamiento Territorial:** Visores prediales y municipales, consumo de servicios **WMS/WMTS** (IGAC, IDEAM, SIAC) y mapas coropléticos.
3. ⚠️ **Gestión del Riesgo de Desastres:** Dashboards en tiempo real con tarjetas KPI, gráficos sincronizados (**Chart.js**) y cálculo de áreas de afectación (*buffers* en el navegador con **Turf.js**).
4. 🌾 **Agricultura y Recursos Hídricos:** Aplicaciones web analíticas en **Python + Streamlit + PyDeck 3D** donde cualquier usuario puede subir sus archivos CSV o GeoJSON.

## 📚 Recursos Maestros del Curso

- 📘 **[Temario Oficial Detallado (`TEMARIO_CURSO.md`)](./TEMARIO_CURSO.md):** Programa académico completo de las 14 horas.
- 🤖 **[Manual Maestro de Prompts Geoespaciales (`PROMPT_PLAYBOOK.md`)](./PROMPT_PLAYBOOK.md):** Más de 20 plantillas de *prompts* listas para copiar, personalizar y pegar en Claude, Gemini o ChatGPT.
- 🚑 **[Guía Rápida de Solución de Errores (`GUIA_SOLUCION_ERRORES.md`)](./GUIA_SOLUCION_ERRORES.md):** Qué hacer cuando el mapa sale en blanco, las coordenadas salen invertidas o falla la carga de un GeoJSON.
- 🗂️ **[Datos de Práctica de Colombia (`./data/`)](./data/):**
  - `estaciones_monitoreo_colombia.geojson`: Red de estaciones hidrometeorológicas y ambientales con variables de alerta, NDVI, precipitación y caudal.
  - `municipios_muestra_colombia.geojson`: Polígonos territoriales con métricas de deforestación, avalúo catastral y riesgo.
  - `muestreo_agro_campo.csv`: Tabla de muestreo agrícola con coordenadas lista para usar en Python y Streamlit.

## ⚡ Cómo empezar en 3 minutos (Modalidad Autodidacta)

1. **Clona o descarga este repositorio:**
   ```bash
   git clone https://github.com/efrainlav/GeoMapIA.git
   cd GeoMapIA
   ```
2. **Explora el Portal Interactivo del Curso:**
   Abre el archivo `index.html` en tu navegador (o usa la extensión **Live Server** en Visual Studio Code) para ver el portal interactivo, probar los visores en vivo y copiar los prompts con un clic.
3. **Avanza módulo por módulo:**
   Entra a la carpeta [`/modulos`](./modulos/), lee el archivo `README.md` de cada módulo, copia los prompts en **Claude** o **Gemini**, compáralos con las soluciones incluidas y realiza el reto corto al final de cada lección.
